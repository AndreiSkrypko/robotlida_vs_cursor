# ⚡ Быстрый старт Telegram бота

## 🎯 Что нужно сделать (3 шага)

### 1️⃣ Создайте бота
1. Откройте Telegram → найдите **@BotFather**
2. Отправьте `/newbot` и следуйте инструкциям
3. **Скопируйте токен** (вида: `1234567890:ABCdefGHI...`)

### 2️⃣ Получите Chat ID
1. Найдите в Telegram → **@userinfobot**
2. Отправьте любое сообщение
3. **Скопируйте ваш Id** (например: `123456789`)

### 3️⃣ Настройте settings.py
Откройте `robototehnika/robototehnika/settings.py` и в конце файла замените:

```python
TELEGRAM_BOT_TOKEN = '1234567890:ABCdefGHI...'  # ← Вставьте ваш токен
TELEGRAM_CHAT_ID = '123456789'  # ← Вставьте ваш chat_id
```

## ✅ Готово!

Теперь при каждой новой записи на курс вам будет приходить уведомление в Telegram на номер +375291210908.
