# 🤖 Настройка Telegram бота для уведомлений о новых записях на курсы

## 📋 Описание

Telegram бот автоматически отправляет уведомления на указанный номер телефона (+375291210908) при каждой новой записи на курсы через сайт.

## 🚀 Пошаговая инструкция по настройке

### Шаг 1: Создание бота в Telegram

1. Откройте Telegram и найдите бота **@BotFather**
2. Отправьте команду `/newbot`
3. Введите имя для вашего бота (например: "IT Клуб Юные Инженеры Уведомления")
4. Придумайте username для бота (должен заканчиваться на `bot`, например: `robotlida_notify_bot`)
5. **@BotFather** отправит вам токен бота вида: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`
6. **Сохраните этот токен** - он понадобится для настройки

### Шаг 2: Получение Chat ID

#### Вариант А: Через @userinfobot (рекомендуется)

1. Найдите в Telegram бота **@userinfobot**
2. Отправьте ему любое сообщение
3. Бот вернет ваш **Id** (например: `123456789`)
4. Это и есть ваш `chat_id`

#### Вариант Б: Через API (альтернатива)

1. Найдите своего созданного бота по username
2. Нажмите **Start** или отправьте ему любое сообщение
3. Откройте в браузере: `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
4. Найдите в JSON ответе значение `"id"` внутри `"chat"` - это ваш `chat_id`

### Шаг 3: Настройка проекта Django

1. Откройте файл `robototehnika/robototehnika/settings.py`

2. Найдите раздел `# === Настройки Telegram Bot ===` (в конце файла)

3. Замените значения на свои:

```python
# === Настройки Telegram Bot ===
TELEGRAM_BOT_TOKEN = '1234567890:ABCdefGHIjklMNOpqrsTUVwxyz'  # Ваш токен от @BotFather
TELEGRAM_CHAT_ID = '123456789'  # Ваш Chat ID
```

### Шаг 4: Установка зависимостей

Установите библиотеку `requests` (если еще не установлена):

```bash
pip install -r requirements.txt
```

Или отдельно:

```bash
pip install requests==2.32.3
```

### Шаг 5: Проверка работы

1. Запустите Django сервер:
```bash
python manage.py runserver
```

2. Создайте тестовую запись на курс через сайт

3. Проверьте Telegram - должно прийти уведомление в формате:

```
🎓 Новая запись на курс!

👤 Имя: Иван Иванов
📱 Телефон: +375291234567
📚 Курс: детям 7-9 лет
💬 Комментарий: Хотел бы узнать подробнее о расписании

🕐 Время: 12.10.2025 14:30
```

## 🔒 Безопасность

### Важно! Защита токена и chat_id

**Не коммитьте токен и chat_id в Git!**

Для продакшена рекомендуется использовать переменные окружения:

1. Создайте файл `.env` в корне проекта:
```
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
TELEGRAM_CHAT_ID=123456789
```

2. Добавьте `.env` в `.gitignore`:
```
.env
```

3. Обновите `settings.py`:
```python
import os
from dotenv import load_dotenv

load_dotenv()

TELEGRAM_BOT_TOKEN = os.getenv('TELEGRAM_BOT_TOKEN', 'YOUR_BOT_TOKEN_HERE')
TELEGRAM_CHAT_ID = os.getenv('TELEGRAM_CHAT_ID', 'YOUR_CHAT_ID_HERE')
```

## 🛠️ Техническая информация

### Структура файлов

- `main_app/telegram_bot.py` - утилиты для отправки сообщений в Telegram
- `main_app/signals.py` - Django signals для автоматической отправки уведомлений
- `main_app/apps.py` - регистрация signals при запуске приложения

### Как это работает

1. Пользователь заполняет форму записи на курс на сайте
2. Django сохраняет запись в модель `Sign`
3. Django signal `post_save` срабатывает автоматически
4. Функция `notify_new_signup()` форматирует сообщение
5. Сообщение отправляется через Telegram Bot API

### Логирование

Все события логируются в Django logger:
- ✅ Успешная отправка: `INFO`
- ❌ Ошибки: `ERROR`

Чтобы увидеть логи, добавьте в `settings.py`:

```python
LOGGING = {
    'version': 1,
    'disable_existing_loggers': False,
    'handlers': {
        'console': {
            'class': 'logging.StreamHandler',
        },
    },
    'loggers': {
        'main_app.telegram_bot': {
            'handlers': ['console'],
            'level': 'INFO',
        },
        'main_app.signals': {
            'handlers': ['console'],
            'level': 'INFO',
        },
    },
}
```

## 🔧 Устранение неполадок

### Проблема: Сообщения не приходят

**Проверьте:**
1. Правильно ли указан токен и chat_id в `settings.py`
2. Нажали ли вы **Start** у бота (обязательно!)
3. Есть ли интернет соединение на сервере
4. Проверьте логи Django на наличие ошибок

### Проблема: Ошибка 401 Unauthorized

**Решение:** Неправильный токен бота. Проверьте токен в `settings.py`

### Проблема: Ошибка 400 Bad Request (chat not found)

**Решение:** 
1. Убедитесь, что вы нажали **Start** у своего бота
2. Проверьте правильность `chat_id`

### Проблема: Бот не отвечает

**Решение:**
1. Проверьте, что бот не забанен/удален
2. Создайте нового бота через @BotFather

```python

```

### Кастомизация сообщений

Отредактируйте функцию `format_new_signup_message()` в `telegram_bot.py` для изменения формата уведомлений.
